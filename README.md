## Pasos para sincronizar con Internet
0. **Pull**. No sabemos si alguien ha hecho cambios en internet. Deberiamos descargarlos 
0. En cuanto escribimos algo q esta sin grabar, en la pestaña de archivo sale un punto gordo, para avisarnos.
1. Grabar los cambios (Ctrl + S) - Aparece una marca en el icono de *source control* con el número de archivos en el q hemos guardado cambios.
2. **Stage**: Marcar los archivos cambiados para q se preparen para ser "controlados" por el sistema.
3. **Commit**: Añadir los archivos marcados a un nuevo punto de control de versiones.
4. **Push**: subir lo que tenemos en nuestro ordenador 

## Errores
1. **No hacer stage**. Si no le dais al `+`, no hay nada que confirmar. El programa te sugiere añadir ek mismo los cambios.
2. **No poner mensaje de commit**. El prgrama abre una pestaña para q lo ponga. Hay que escribirlo, guardar y cerrar esa pestaña
3. **Olvidar sincronizar**. Esto no puedo saltarmelo.
